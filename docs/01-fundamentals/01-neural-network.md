# 神经网络介绍

**神经网络（Neural Network，又称人工神经网络 ANN）**是一种受人类大脑神经元连接方式启发而设计的机器学习模型。它通过大量简单的计算单元分层连接，从数据中自动学习特征和规律，是现代深度学习（Deep Learning）的核心基础。

---

## 1. 基本结构

一个典型的神经网络由多层**神经元（节点）**组成：

* **输入层（Input Layer）**：接收原始数据（如图像的像素值、文本的向量、表格的特征值）。
* **隐藏层（Hidden Layers）**：位于输入和输出之间，负责逐层提取和组合抽象特征。隐藏层越多，网络通常越“深”（即**深度学习**）。
* **输出层（Output Layer）**：给出最终预测结果（如分类概率、回归数值或下一个词的概率分布）。

### 单个神经元如何工作？

每个神经元接收上一层的输入 $x_1, x_2, \dots, x_n$，按各自的**权重** $w_i$ 加权求和，加上**偏置** $b$，再通过一个**激活函数** $\sigma$ 输出：

$$
y = \sigma\left(\sum_{i=1}^{n} w_i x_i + b\right)
$$

* **权重（Weight）与偏置（Bias）**：网络需要学习的“参数”，决定了不同输入的重要性。
* **激活函数（Activation Function）**：如 `ReLU`、`Sigmoid`、`GELU` 等，用于引入**非线性**，使网络能够拟合复杂的非线性关系（否则多层线性叠加仍等价于单层线性模型，详见 [激活函数介绍](./03-activation-functions.md)）。

---

## 2. 神经网络是如何“学习”的？

训练神经网络的核心目标是**调整所有权重和偏置，使预测结果尽可能接近真实标签**。一次典型的训练迭代包含 4 个步骤：

1. **前向传播（Forward Propagation）**：数据从输入层流经隐藏层到达输出层，得到预测值。
2. **计算损失（Loss Calculation）**：用**损失函数**（如均方误差 MSE、交叉熵 Cross-Entropy）衡量预测值与真实值的差距。
3. **反向传播（Backpropagation）**：利用微积分的链式法则，从输出层反向计算损失对每个参数的梯度（即每个参数该往哪个方向调整才能减小误差）。
4. **参数更新（Optimization）**：通过优化器（如 `SGD`、`Adam`）沿着梯度的反方向微调参数（梯度下降），不断重复上述过程直到模型收敛。

## 3. 常见的神经网络架构

不同类型的数据通常对应不同的网络结构：

| 网络类型 | 特点 | 典型应用 |
| :--- | :--- | :--- |
| **[前馈神经网络（MLP / FNN）](../02-architectures/01-mlp-and-fnn.md)** | 最基础的全连接结构，数据单向流动 | 表格数据预测、简单分类/回归 |
| **[卷积神经网络（CNN）](../02-architectures/02-cnn.md)** | 利用卷积核提取局部空间特征、共享权重 | 图像分类、目标检测、医学影像分析 |
| **循环神经网络（RNN / LSTM / GRU）** | 带有“记忆”机制，按顺序处理序列数据 | 时间序列预测、早期语音与文本处理 |
| **Transformer** | 基于**自注意力机制（Self-Attention）**，可并行建模长距离依赖 | 大语言模型（GPT、Gemini 等）、机器翻译、多模态模型 |
| **图神经网络（GNN）** | 直接在图结构（节点与边）上传递和聚合信息 | 社交网络分析、推荐系统、分子结构预测 |

---

## 4. 优势与局限

* **优势**：
  * **强大的表达能力**：理论上足够大的神经网络可以逼近任意连续函数（详见 [万能近似定理介绍](./02-universal-approximation-theorem.md)）。
  * **自动特征提取**：无需大量手工设计特征，尤其擅长处理图像、语音、文本等非结构化数据。
* **局限**：
  * **依赖大量数据与算力**：训练深层网络通常需要海量数据和 GPU/TPU 支持。
  * **可解释性弱**：内部决策过程类似“黑盒”，难以直观解释每一步的逻辑。
  * **容易过拟合**：参数过多时可能“死记硬背”训练数据，需要正则化、Dropout 等手段缓解。
