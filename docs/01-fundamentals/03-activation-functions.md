# 激活函数（Activation Functions）介绍

在 [神经网络介绍](./01-neural-network.md)、[万能近似定理介绍](./02-universal-approximation-theorem.md)、[前馈神经网络（MLP / FNN）介绍](../02-architectures/01-mlp-and-fnn.md) 与 [卷积神经网络（CNN）介绍](../02-architectures/02-cnn.md) 中反复提到的 **`Sigmoid`**、**`ReLU`**、**`GELU`** 等，都属于神经网络中的**非线性激活函数（Activation Function）**。

---

## 1. 为什么必须要有非线性激活函数？

在一个神经网络层中，神经元先对输入做线性变换 $z = Wx + b$，再经过激活函数 $\sigma$ 输出 $h = \sigma(z)$。

如果**没有非线性激活函数**（即令 $\sigma(z) = z$），那么即使堆叠多层网络：

$$
y = W^{(2)}\left(W^{(1)} x + b^{(1)}\right) + b^{(2)} = \underbrace{\left(W^{(2)} W^{(1)}\right)}_{W'} x + \underbrace{\left(W^{(2)} b^{(1)} + b^{(2)}\right)}_{b'}
$$

整个多层网络在数学上依然等价于**单层线性变换**，无论加深多少层都只能拟合直线或超平面，无法表达异或（XOR）、图像边缘组合、自然语言语义等复杂非线性规律。

因此，激活函数的核心职责有两点：

1. **引入非线性表达能力**：使多层网络突破线性限制，满足 [万能近似定理](./02-universal-approximation-theorem.md) 的前提条件（非多项式函数）。
2. **影响梯度流动与训练稳定性**：反向传播时，梯度会逐层乘以激活函数的导数；激活函数导数的大小和形态直接决定了深层网络会不会出现**梯度消失**、**神经元死亡**或**难以收敛**的问题。

## 2. 核心激活函数详解：`Sigmoid`、`ReLU`、`GELU`

![Sigmoid、ReLU、GELU 函数图像与导数对比](../assets/activation-functions.svg)

### 2.1 `Sigmoid`（S 型函数 / 逻辑函数）

* **全称**：Sigmoid Function（Logistic Function）
* **公式与导数**：
  $$
  \sigma(x) = \frac{1}{1 + e^{-x}}, \qquad \sigma'(x) = \sigma(x)\bigl(1 - \sigma(x)\bigr)
  $$
* **直观形态**：将任意实数平滑压缩到 `(0, 1)` 区间内，图像呈平滑的 “S” 形。输入趋向正无穷时输出趋近 1，趋向负无穷时输出趋近 0；在 $x = 0$ 处输出为 0.5，导数取得最大值 0.25。
* **核心特点**：
  * **优点**：
    * 输出范围严格在 `(0, 1)`，天然具有**概率**或**门控开关比例**的直观含义。
    * 处处平滑可微，早期在理论上常用于构造证明（例如 [万能近似定理](./02-universal-approximation-theorem.md) 中用两个 `Sigmoid` 相减拼出“窄矩形块”）。
  * **缺点**：
    * **容易梯度消失**：当 $|x|$ 较大时曲线两端接近水平，导数趋近于 0；且最大导数仅为 0.25，深层网络反向传播连乘后梯度迅速衰减至接近 0，浅层参数几乎无法更新。
    * **输出非零中心（Non-zero-centered）**：输出恒大于 0，会导致下一层权重梯度同号，优化路径容易出现锯齿形震荡。
    * **计算较慢**：包含指数运算 $e^{-x}$。
* **典型位置**：现代深层网络的**隐藏层已很少使用**，主要用在**二分类输出层**（输出属于正类的概率）、多标签分类输出层，以及门控机制（如 LSTM、注意力/特征门控）中。

---

### 2.2 `ReLU`（修正线性单元）

* **全称**：Rectified Linear Unit
* **公式与导数**：
  $$
  \text{ReLU}(x) = \max(0, x) = \begin{cases} x, & x > 0 \\ 0, & x \le 0 \end{cases}
  \qquad
  \text{ReLU}'(x) = \begin{cases} 1, & x > 0 \\ 0, & x < 0 \end{cases}
  $$
  （在 $x = 0$ 处不可微，工程实现中通常约定导数为 0。）
* **直观形态**：一条在原点折弯的分段折线——正数原样放行，负数和零直接截断归零。
* **核心特点**：
  * **优点**：
    * **大幅缓解梯度消失**：正区间导数恒为 1，梯度在深层网络中可以顺畅向浅层传播（2012 年 AlexNet 引入 `ReLU` 是推动深层 [CNN](../02-architectures/02-cnn.md) 成功训练的关键突破之一）。
    * **计算极快**：前向只需一次与 0 的比较，反向只需判断正负，没有指数或三角运算开销。
    * **稀疏激活**：负输入直接输出 0，使同一时刻只有一部分神经元处于激活状态，计算更高效且有助于提取判别性特征。
  * **缺点**：
    * **神经元死亡（Dying ReLU）**：如果学习率过大或初始化不当，某些神经元的线性输出在所有样本上都落入 $\le 0$ 区间，其梯度将恒为 0，参数从此再也无法更新。
    * **输出同样非零中心**，且在 0 点处存在硬折角（不够平滑）。
* **典型位置与代码示例**：
  * 经典 **CNN** 与 **MLP** 隐藏层最常用的默认激活函数，通常搭配 **He 初始化（Kaiming Initialization）** 使用以保持方差稳定。
  * 在本仓库的 [MLP 房价预测 Demo](../../demos/mlp/house_price_prediction.py) 中，隐藏层直接手写了 `ReLU` 的前向计算（`s if s > 0.0 else 0.0`）与反向梯度传导（`z > 0` 时导数为 1，否则为 0）。

---

### 2.3 `GELU`（高斯误差线性单元）

* **全称**：Gaussian Error Linear Unit
* **公式**：
  $$
  \text{GELU}(x) = x \cdot \Phi(x) = \frac{x}{2}\left(1 + \operatorname{erf}\!\left(\frac{x}{\sqrt{2}}\right)\right)
  $$
  其中 $\Phi(x)$ 为标准正态分布的累积分布函数（CDF），$\operatorname{erf}$ 为高斯误差函数。工程上常使用基于 $\tanh$ 的快速近似：
  $$
  \text{GELU}(x) \approx 0.5x \left(1 + \tanh\!\left(\sqrt{\frac{2}{\pi}}\left(x + 0.044715 x^3\right)\right)\right)
  $$
* **直观形态**：可以理解为 **`ReLU` 的平滑概率版本**。`ReLU` 是在 0 点“一刀切”（乘以阶跃函数 $\mathbb{I}(x > 0)$），而 `GELU` 乘以的是输入在标准正态分布下的累积概率 $\Phi(x)$：
  * 当 $x$ 较大为正时，$\Phi(x) \to 1$，几乎原样保留 $x$；
  * 当 $x$ 在 0 附近略小于 0 时，不会立刻归零，而是保留一小段平滑的负值凹陷（最小值约 `-0.17`）；
  * 当 $x$ 很负时，$\Phi(x) \to 0$，平滑趋近于 0。
* **核心特点**：
  * **优点**：
    * **处处平滑可微**：消除了 `ReLU` 在 0 点处的折角，梯度变化连续，在深层大规模模型中优化更加稳定。
    * **缓解神经元死亡**：在负半轴靠近 0 的区域保留了非零梯度，避免神经元轻易“锁死”。
    * **表达与收敛优势**：在自然语言处理与视觉 Transformer 任务中，经验表现通常优于标准 `ReLU`。
  * **缺点**：计算复杂度高于 `ReLU`（但在现代 GPU 上通常通过算子融合高效执行）。
* **典型位置**：**Transformer 与大语言模型**（如 BERT、GPT 系列、ViT、ConvNeXt 等）的 FFN 层标配激活函数之一（详见 [MLP / FNN 介绍](../02-architectures/01-mlp-and-fnn.md) 中对 Transformer FFN 的说明）。

## 3. 其他常用激活函数与衍生家族

除了上述三个核心代表，深度学习工程与论文中还按不同需求衍生出了四大类常用激活函数。下方先汇总 8 个常见一元激活函数的图像与导数曲线（多维门控 `SwiGLU / GeGLU` 与向量归一化 `Softmax` 见下方文字说明）：

![其他常见激活函数图像与导数对比](../assets/activation-functions-more.svg)

### 3.1 经典 S 型家族

* **`Tanh`（双曲正切）**：$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$，导数为 $1 - \tanh^2(x)$
  * **特点**：输出范围 `(-1, 1)`，是“零中心化”的 `Sigmoid` 变体，中心处最大导数为 1（比 `Sigmoid` 的 0.25 更陡），但两端依然存在梯度消失。
  * **常见场景**：传统 RNN / LSTM / GRU 的隐藏状态计算，以及部分图像生成模型（像素归一化到 `[-1, 1]`）的输出层。

### 3.2 `ReLU` 改进家族（解决神经元死亡与端侧量化）

* **`LeakyReLU` / `PReLU`**
  * **公式**：$x > 0$ 时为 $x$，否则为 $\alpha x$（`LeakyReLU` 通常取固定 $\alpha = 0.01$；`PReLU` 将 $\alpha$ 设为可学习参数）。
  * **特点与场景**：给负半轴留出微小非零斜率，直接解决“神经元死亡”问题；常见于 GAN（如 DCGAN）和早期目标检测网络。
* **`ELU` / `SELU`**
  * **公式**：`ELU` 在 $x \le 0$ 时为 $\alpha(e^x - 1)$，平滑趋近 $-\alpha$；`SELU` 在 `ELU` 基础上乘以特定缩放系数 $\lambda \approx 1.0507$（取 $\alpha \approx 1.6733$）。
  * **特点与场景**：负区平滑饱和且输出均值更接近 0；`SELU` 配合特定权重初始化可使各层输出自发趋向零均值、单位方差（自归一化网络）。
* **`ReLU6`**
  * **公式**：$\min(\max(0, x), 6)$
  * **特点与场景**：将输出限制在 `[0, 6]` 之间，防止激活值过大导致低精度量化（FP16 / INT8）精度损失；广泛用于 MobileNetV1 / V2 等手机端轻量模型。

### 3.3 现代平滑与门控家族（当代视觉与大语言模型主力）

* **`SiLU`（又称 `Swish`）**
  * **公式**：$x \cdot \sigma(x)$
  * **特点与场景**：用 `Sigmoid` 替代 `GELU` 中的高斯 CDF $\Phi(x)$，曲线同样呈带轻微负凹坑（最低约 `-0.28`）的“圆角 ReLU”，但计算更简洁；是 EfficientNet、YOLOv5/v8、Stable Diffusion U-Net 等现代视觉与扩散模型的标配。
* **`HardSwish` / `HardSigmoid`**
  * **公式**：$\text{HardSwish}(x) = x \cdot \frac{\text{ReLU6}(x + 3)}{6}$
  * **特点与场景**：用分段线性函数近似 `Swish`（和 `Sigmoid`），彻底消除指数运算，专为移动端与边缘端芯片加速设计（如 MobileNetV3）。
* **`Mish`**
  * **公式**：$x \cdot \tanh(\ln(1 + e^x))$
  * **特点与场景**：形态类似更平滑的 `SiLU`（最低约 `-0.31`），在 YOLOv4 等检测网络中表现优异，但计算开销略高于 `SiLU`。
* **`SwiGLU` / `GeGLU`（GLU 门控线性单元家族）**
  * **公式**：$\text{SwiGLU}(x) = \text{SiLU}(xW_1) \odot (xW_2)$（将 `SiLU` 换成 `GELU` 即为 `GeGLU`，$\odot$ 表示逐元素相乘）。
  * **特点与场景**：并非单一标量函数，而是由两条线性投影分支组成的**门控结构**——一路经平滑激活后作为动态“开关”去调制另一路输出，表达能力强于传统两层 FFN。已成为 **LLaMA、Qwen、DeepSeek、Mistral、Gemma** 等现代大语言模型 FFN 层的绝对主流。

### 3.4 输出层与特殊约束专用

* **`Softmax`**
  * **公式**：$\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}$
  * **特点与场景**：作用于整个向量的多维归一化函数，将一组类别得分转化为和为 1 的概率分布；用于**单标签多分类输出层**、**Transformer 自注意力权重归一化**以及**大语言模型预测下一个 Token 的词表概率**。
* **`Softplus`**
  * **公式**：$\ln(1 + e^x)$（其导数恰好就是 `Sigmoid` 函数 $\sigma(x)$）
  * **特点与场景**：`ReLU` 的处处光滑且**严格大于 0** 的近似版本（过点 `(0, ln 2 ≈ 0.69)`）；常用于需要网络输出严格正值的任务（如预测高斯分布的标准差/方差、时间间隔或强度参数）。

## 4. 横向对比与工程选型建议

### 核心与主流激活函数速查

| 激活函数 | 输出范围 | 曲线 / 结构形态 | 核心优势 | 主要局限 | 典型位置 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **`Sigmoid`** | `(0, 1)` | 平滑 S 形 | 输出具概率含义、适合门控 | 易梯度消失、非零中心、计算较慢 | 二分类输出层、门控单元 |
| **`Tanh`** | `(-1, 1)` | 零中心平滑 S 形 | 零中心化、中心梯度更大 | 两端仍易梯度消失 | 传统 RNN / LSTM、归一化输出 |
| **`ReLU`** | `[0, +∞)` | 0 点硬折线 | 计算极快、缓解梯度消失、稀疏激活 | 负区可能出现神经元死亡 | CNN / MLP 隐藏层 |
| **`LeakyReLU` / `ELU`** | `(-∞, +∞)` / `(-α, +∞)` | 负区带斜率或平滑饱和 | 避免神经元死亡 | 多一个超参数 $\alpha$ | GAN、部分 CNN / 表格网络 |
| **`ReLU6` / `HardSwish`** | `[0, 6]` / 约 `[-0.375, +∞)` | 截断折线 / 分段近似 | 量化友好、无指数运算 | 表达力略让位于推理效率 | MobileNet 等端侧模型 |
| **`SiLU` / `Mish`** | 约 `[-0.28, +∞)` / `[-0.31, +∞)` | 平滑类 ReLU | 处处光滑、视觉任务表现优 | 计算较 `ReLU` 略重 | EfficientNet、YOLO、扩散模型 |
| **`GELU`** | 约 `[-0.17, +∞)` | 高斯加权平滑类 ReLU | 处处光滑、训练稳定、大模型效果好 | 计算比 `ReLU` 略复杂 | BERT / GPT / ViT 的 FFN 层 |
| **`SwiGLU` / `GeGLU`** | 实数向量 | 双分支门控线性单元 | 门控交互表达力更强 | 需额外投影矩阵，计算量略增 | LLaMA / Qwen / DeepSeek / Gemma |

> **演进脉络速记**：早期 **`Sigmoid` / `Tanh`** → 深度学习爆发 **`ReLU` 及其变体**（`LeakyReLU` / `ReLU6`）→ 现代视觉与大模型主力 **`SiLU` / `GELU` / `SwiGLU`**。

### 实用选型原则

1. **隐藏层选择**：
   * 常规 **MLP / 传统 CNN**：优先用 **`ReLU`**（若观察到训练停滞或大量神经元死亡，可换用 **`LeakyReLU`**、**`ELU`** 或 **`SiLU`**）。
   * **端侧 / 轻量化视觉模型**：考虑 **`ReLU6`** 或 **`HardSwish`**（量化更稳、推理更快）。
   * **现代 CNN / 目标检测 / 扩散模型**：常用 **`SiLU`**（或 `Mish`）。
   * **Transformer / ViT / 现代大语言模型**：优先用 **`GELU`** 或 **`SwiGLU`**。
   * 一般**不要**在深层网络的隐藏层中使用 `Sigmoid`。
2. **输出层选择（取决于任务类型）**：
   * **回归任务**（如房价预测）：通常**不加激活函数**（线性输出），直接输出任意实数；若要求输出严格为正（如标准差），可用 **`Softplus`**。
   * **二分类 / 多标签分类**：使用 **`Sigmoid`** 输出各标签的独立概率。
   * **单标签多分类**：使用 **`Softmax`** 输出互斥类别的概率分布。
3. **配合合适的参数初始化**：
   * 使用 `ReLU` 及其变体时，推荐配合 **He 初始化**（如 [MLP 房价预测 Demo](../../demos/mlp/house_price_prediction.py) 中的做法）；
   * 使用 `Sigmoid` / `Tanh` 时，推荐配合 **Xavier（Glorot）初始化**，以防止前向信号和反向梯度逐层爆炸或衰减。
