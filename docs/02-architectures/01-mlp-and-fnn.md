# 前馈神经网络（MLP / FNN）介绍

在 [神经网络介绍](../01-fundamentals/01-neural-network.md) 中提到的 **MLP / FNN**，是深度学习中最基础、最经典的一类网络架构——**前馈神经网络**。

---

## 1. 名称与关系

* **FNN（Feedforward Neural Network，前馈神经网络）**
  * **广义概念**：指数据只沿**单一方向**（输入层 → 隐藏层 → 输出层）向前流动、网络内部**没有循环或反馈连接**（无环图）的神经网络。
  * 与之相对的是带有循环反馈连接的 **RNN**（循环神经网络）。
* **MLP（Multilayer Perceptron，多层感知机）**
  * **FNN 最经典、最狭义的代表**：特指由**输入层 + 至少一个隐藏层 + 输出层**组成，且相邻层之间采用**全连接（Fully Connected / Dense）**并带有非线性激活函数的网络。
  * 在工程与教程中，由于全连接前馈网络最常见，**MLP** 和 **FNN** 经常被当作同义词混用。

> **补充（常见易混词 FFN）**：在阅读 Transformer / 大模型相关资料时常会看到 **FFN（Feed-Forward Network）**，它指 Transformer 每个模块中跟在自注意力层后面的前馈子层，本质上就是一个 2 层的 MLP。

---

## 2. 结构与计算方式

单个神经元的计算方式是加权求和、加偏置后再经过激活函数。**MLP** 就是把大量这样的神经元排成多层，且**上一层的每个神经元都与下一层的所有神经元相连**。

若把第 $l-1$ 层的输出写成向量 $h^{(l-1)}$，则第 $l$ 层的计算可以用一次矩阵乘法加激活函数表示：

$$
h^{(l)} = \sigma\left(W^{(l)} h^{(l-1)} + b^{(l)}\right)
$$

* $W^{(l)}$：当前层的权重矩阵；
* $b^{(l)}$：偏置向量；
* $\sigma$：非线性激活函数（如 `ReLU`、`GELU`、`Sigmoid`）。

训练过程遵循标准的神经网络训练流程：**前向传播 → 计算损失 → 反向传播 → 梯度下降更新参数**。

---

## 3. 为什么叫“多层感知机”？

早期只有输入层和输出层的**单层感知机（Perceptron）**本质上是线性分类器，连简单的**异或（XOR）**问题都无法解决。引入**隐藏层 + 非线性激活函数**后：

1. 隐藏层能自动把原始特征映射到新的特征空间，使原本线性不可分的数据变得可分；
2. 根据 [万能近似定理（Universal Approximation Theorem）](../01-fundamentals/02-universal-approximation-theorem.md)，只要隐藏层宽度足够，哪怕只含一个隐藏层的 MLP 理论上也能逼近任意连续函数。

---

## 4. 典型用途与局限

| 维度 | 说明 |
| :--- | :--- |
| **擅长场景** | 1. **表格/结构化数据**的分类与回归任务（如房价预测、风控评分）<br>2. 作为**基础积木**嵌入更复杂的架构中，例如 [CNN](./02-cnn.md) 末尾的全连接分类头、Transformer 中的 FFN 层、投影层（Projection Head） |
| **主要局限** | 1. **参数量爆炸**：输入维度大时（如高分辨率图像），全连接权重数量会急剧膨胀，极易过拟合<br>2. **缺少结构先验**：把输入展平为一维向量，会丢失图像的二维空间局部关系（图像多用 [CNN](./02-cnn.md)）和文本的序列/长程依赖关系（文本多用 RNN / Transformer） |

---

## 5. 擅长场景详解

### 5.1 表格 / 结构化数据的分类与回归任务

这类数据通常像一张 Excel 或数据库表：每一行是一个样本，每一列是一个固定含义的特征（如面积、房龄、收入、历史逾期次数等）。

**为什么 MLP 适合这类数据？**

1. **输入形式天然匹配**：表格的每一行本身就是定长的一维特征向量，各列之间没有图像的二维空间相邻关系，也没有文本的严格前后词序关系，直接送入全连接层不会丢失结构信息。
2. **维度可控，不易参数爆炸**：表格特征数通常在几十到几百维（远小于高分辨率图像的百万级像素），全连接层参数量在可控范围内。
3. **自动学习特征间的非线性组合**：全连接使隐藏层的每个神经元都能同时看到所有输入特征，经多层非线性激活后能自动学到高阶特征交互（例如将“高负债率 + 近期频繁借贷 + 收入下降”组合成高违约风险信号），减少手工交叉特征工程。

**典型任务划分：**

* **回归任务（输出连续数值）**：房价预测（可运行示例见 [MLP 房价预测 Demo](../../demos/mlp/house_price_prediction.py)）、商品销量预估、物流时长预测、金融资产估值、设备剩余寿命预测等。
* **分类任务（输出类别或概率）**：风控违约预测、反欺诈识别、用户流失预警、广告点击率（CTR）预估、医学化验指标辅助诊断等。

> **工程实践补充**：在**中小规模纯表格数据**上，梯度提升树（XGBoost / LightGBM / CatBoost）往往比纯 MLP 更易取得好效果（对缺失值、异常值和不同量纲更鲁棒，且训练快）。MLP 在表格场景下的独特优势主要体现在**超大规模数据与在线学习**（如推荐/广告系统中的 DeepFM、Wide & Deep、DLRM 等），以及**多模态融合**（当表格特征需与文本向量、图像特征一起端到端联合训练时，MLP 可直接拼接并统一反向传播）。

### 5.2 作为“基础积木”嵌入更复杂的现代架构中

在现代深度学习中，虽然很少直接用纯 MLP 处理原始图片像素或原始文本词序，但几乎所有主流模型内部都离不开 MLP——它通常承担**非线性特征加工、语义空间对齐与最终汇总决策**的角色。

1. **CNN 末尾的全连接分类头（Classification Head）**
   * **分工机制**：前半段的卷积层与池化层负责提取二维空间结构特征，并将图像逐步抽象、压缩成一个定长的一维全局特征向量（如 512 或 2048 维）；末尾的 MLP（通常为 1～3 层全连接）将这一维语义向量汇总并映射到各个类别得分，再经 Softmax 输出概率。
   * **适用原因**：到此阶段空间位置信息已完成提取与汇总、维度也大幅降低，正需要全连接来做全局语义整合与最终分类决策。
2. **Transformer 中的 FFN 层（Feed-Forward Network）**
   * **本质结构**：在 GPT、Gemini、LLaMA 等大语言模型中，每个 Transformer Block 都由 **Self-Attention + FFN** 组成。FFN 本质上是对每个 Token 独立计算的 **2 层 MLP**，常见做法是“先升维再降维”（如将维度放大约 4 倍，经 `GELU` / `SwiGLU` 激活后再投影回原维度）。
   * **核心作用**：Self-Attention 负责**跨 Token 通信**（决定当前词关注上下文中的哪些词）；FFN（MLP）则负责**单 Token 内部的深度非线性变换**。在现代 LLM 中，FFN 往往占据约 **2/3 的参数量**，许多可解释性研究认为它类似于隐式的**键值记忆库（Key-Value Memory）**，存储了大量事实性知识与语义映射规律。
3. **投影层（Projection Head / Projector）**
   * 用 1～2 层轻量级 MLP 将特征向量从一个表示空间**映射/翻译**到另一个目标空间，常见于两类场景：
     * **多模态大模型中的“翻译器”（如 LLaVA 等视觉语言模型）**：视觉编码器（如 ViT）提取的图像特征与大语言模型的文本词向量处于不同语义空间且维度不同，通过 2 层 MLP（Projector）可将图像特征对齐为大语言模型可理解的视觉 Token。
     * **对比学习 / 自监督学习（如 SimCLR）**：训练时在主干网络后接 2 层 MLP，把特征投影到计算对比损失的空间；训练完成用于下游任务时通常移除该 MLP、只保留主干编码器，从而避免主干为迎合对比损失而丢失下游有用信息。

### 5.3 小结：MLP 的核心定位

| 使用方式 | 面对的数据特征 | MLP 承担的核心角色 |
| :--- | :--- | :--- |
| **独立作为主模型** | 低/中维、无空间或时序先验的**表格/结构化向量** | 端到端完成特征交互与分类/回归预测 |
| **作为组件嵌入大模型** | 已被 CNN / Transformer / 编码器提取好的**高维抽象特征向量** | 1. 汇总决策（分类头）<br>2. 非线性变换与知识存储（Transformer FFN）<br>3. 跨模态/跨空间对齐（Projection Head） |

归根结底，MLP **不擅长直接从高维原始数据中提取空间或时序结构**，但非常擅长**在特征已被整理成合适向量之后，执行通用的非线性函数拟合与空间变换**——这正是它至今仍是深度学习最核心基础积木的原因。
