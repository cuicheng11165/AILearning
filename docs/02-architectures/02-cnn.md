# 卷积神经网络（CNN）介绍

在 [神经网络介绍](../01-fundamentals/01-neural-network.md) 与 [前馈神经网络（MLP / FNN）介绍](./01-mlp-and-fnn.md) 中提到的 **CNN（Convolutional Neural Network，卷积神经网络）**，是一类专门为处理**具有网格结构的数据**（尤其是二维图像，以及一维音频、三维视频等）而设计的深度学习架构。

---

## 1. 为什么需要 CNN？（相对 MLP 的突破）

在 [前馈神经网络（MLP / FNN）介绍](./01-mlp-and-fnn.md) 中提到，全连接网络（MLP）直接处理高分辨率图像时会面临两大瓶颈：

1. **参数量爆炸**：一张常见的 `224×224×3` 彩色图片展平后有 150,528 个输入数值。如果第一个隐藏层有 1,000 个神经元，仅这一层就需要约 **1.5 亿** 个权重参数，极难训练且极易过拟合。
2. **丢失二维空间结构**：将图像强行展平为一维向量后，像素之间原本“上下左右相邻”的几何位置关系会被打散。

CNN 通过在网络结构中引入两条符合图像规律的**归纳偏置（结构先验）**解决了上述问题：

* **局部连接（局部感受野，Local Receptive Field）**：图像中的基础模式（如边缘、角点、局部纹理）都是局部的。每个神经元只与输入的一小块局部区域（如 `3×3` 窗口）相连，而不是全连接。
* **权重共享（Weight Sharing）**：同一个**卷积核（Filter / Kernel）**会在整张图像上滑动扫描。无论“一条竖边”或“一只猫耳朵”出现在图像左上角还是右下角，都共用同一组参数去检测——既将单层参数量从亿级压缩到几十～几千级，又天然赋予网络**平移等变性 / 平移不变性**。

## 2. 核心组件与工作流程

一个经典的 CNN 通常按“**特征提取主干 + 决策头**”串联而成：

```text
输入图像 → [卷积层 + 激活函数 → 池化层] × N → 展平 / 全局平均池化 → 全连接层 (MLP) → 输出结果
```

### 2.1 卷积层（Convolutional Layer）

卷积层是 CNN 的核心。它包含多个可学习的**卷积核**（例如大小为 $K \times K$，常见为 `3×3`）。单个卷积核在输入特征图上按固定步幅滑动，在每个位置做逐元素相乘求和并加上偏置，生成一张二维的**特征图（Feature Map）**：

$$
Y(i, j) = \sum_{c=1}^{C_{\text{in}}} \sum_{m=0}^{K-1} \sum_{n=0}^{K-1} X(c, i \cdot s + m, j \cdot s + n) \cdot W(c, m, n) + b
$$

* **通道（Channel）**：输入图像的通道数 $C_{\text{in}}$（如 RGB 彩色图为 3）；使用 $C_{\text{out}}$ 个不同的卷积核，就会输出 $C_{\text{out}}$ 张特征图，每张特征图对应一种被检测到的视觉模式。
* **步幅（Stride, $s$）**：卷积核每次滑动的像素格数。$s=1$ 逐像素扫描；$s=2$ 会使输出的高和宽减半。
* **填充（Padding, $p$）**：在特征图边缘补零（Zero Padding），用于控制输出尺寸不被过快缩小，同时防止边缘像素信息利用不足。

在输入边长为 $H$、卷积核边长为 $K$、填充为 $p$、步幅为 $s$ 时，输出边长为：

$$
H_{\text{out}} = \left\lfloor \frac{H + 2p - K}{s} \right\rfloor + 1
$$

### 2.2 激活层（Activation Layer）

紧跟在卷积层之后，最常用 `ReLU`（以及 `LeakyReLU`、`GELU`、`SiLU` 等），用于引入**非线性**（详见 [激活函数介绍](../01-fundamentals/03-activation-functions.md)）。如果没有非线性激活，多层卷积叠加在数学上仍等价于单层线性变换。

### 2.3 池化层（Pooling Layer）

对特征图做空间下采样（如 `2×2` 窗口、步幅为 2），常见方式包括：

* **最大池化（Max Pooling）**：取窗口内的最大值，突出最显著的特征响应。
* **平均池化（Average Pooling）**：取窗口内的平均值，保留区域整体信息。
* **全局平均池化（Global Average Pooling, GAP）**：将每张特征图直接求均值压缩为 1 个标量，常用于网络末尾替代庞大的展平操作，大幅减少全连接层参数并抑制过拟合。

池化层的主要作用是**降低特征图分辨率与计算量、扩大深层神经元的感受野、增强对目标轻微位移或形变的鲁棒性**。现代 CNN 中也常直接用 `Stride = 2` 的卷积代替独立池化层。

### 2.4 全连接分类头（Classification Head / MLP）

如 [前馈神经网络（MLP / FNN）介绍](./01-mlp-and-fnn.md) 所述，经过多轮卷积与池化后，原始图像已被逐步抽象并压缩成一个定长的一维全局语义向量（如 512 或 2048 维）。末尾的 1～3 层全连接网络（MLP）负责整合这些全局特征，映射到各个目标类别得分，再经 `Softmax` 输出概率分布。

## 3. 层级特征提取：CNN 如何“看懂”图像？

结合 [万能近似定理介绍](../01-fundamentals/02-universal-approximation-theorem.md) 中提到的“深度复用”思想，多层卷积堆叠会自发形成由低级到高级的**层次化视觉表示**：

1. **浅层卷积**：感受野较小，主要学习通用的低级特征，如**水平/竖直边缘、颜色渐变、明暗对比**。
2. **中层卷积**：把浅层的边缘组合成更复杂的**纹理、几何形状和局部部件**（如眼睛、耳朵、车轮、窗格）。
3. **深层卷积**：感受野覆盖整张图像的大部分区域，把局部部件组合成**完整物体与高级语义**（如猫、汽车、建筑）。

> **工程补充**：正因为浅层与中层学到的边缘、纹理特征在不同视觉任务间高度通用，CNN 非常适合做**迁移学习（Transfer Learning）**——先在大型通用数据集（如 ImageNet）上预训练主干网络，再用少量特定领域数据微调即可取得良好效果。

## 4. 经典架构演进

| 架构 | 年份 | 核心突破与意义 |
| :--- | :--- | :--- |
| **LeNet-5** | 1998 | 奠定“卷积 → 池化 → 全连接”经典范式，成功应用于手写数字识别 |
| **AlexNet** | 2012 | 引入 `ReLU`、Dropout、数据增强与 GPU 并行训练，在 ImageNet 竞赛中大幅领先，引爆现代深度学习浪潮 |
| **VGG** | 2014 | 证明连续堆叠多个小卷积核（`3×3`）比单个大卷积核（如 `5×5`、`7×7`）感受野相同、参数更少且非线性表达更强 |
| **GoogLeNet / Inception** | 2014 | 在同一层并行使用多尺度卷积核，并引入 `1×1` 卷积做跨通道降维与特征融合 |
| **ResNet** | 2015 | 提出**残差连接（Skip Connection）** $y = F(x) + x$，有效缓解深层网络的梯度消失与退化问题，使百层以上网络可稳定训练 |
| **MobileNet / EfficientNet** | 2017–2019 | 引入深度可分离卷积与复合缩放策略，大幅降低参数量与算力消耗，推动视觉模型在手机与边缘端落地 |
| **ConvNeXt** | 2022 | 吸收 Vision Transformer 的设计理念（大卷积核、LayerNorm、倒瓶颈结构等）对纯 CNN 现代化改造，展现极强竞争力 |

## 5. 典型应用场景

* **计算机视觉核心任务**：
  * **图像分类**：识别整张图片的类别（如 ResNet、EfficientNet）。
  * **目标检测**：定位图中多个物体并分类（如 YOLO 系列、Faster R-CNN）。
  * **语义 / 实例分割**：对图像中每个像素进行分类（如 U-Net、Mask R-CNN）。
  * **其他视觉任务**：人脸识别、文字识别（OCR）、图像超分辨率与去噪。
* **专业影像与遥感**：医学影像分析（CT / MRI / X 光病灶检测与分割）、工业缺陷质检、卫星遥感解译。
* **非二维网格数据**：
  * **1D-CNN**：处理一维序列的局部模式，如音频波形、心电图（ECG）、传感器振动信号。
  * **3D-CNN**：在空间二维基础上增加时间或深度维度，用于视频动作识别、三维医学体数据分析。

## 6. 优势、局限与现代定位（对比 Vision Transformer）

| 维度 | 说明 |
| :--- | :--- |
| **主要优势** | 1. **数据效率高**：局部性与平移不变性先验强，在**中小规模数据集**上比纯注意力模型更易训练且不易过拟合<br>2. **计算与推理高效**：局部滑动窗口计算复杂度与像素数呈线性关系，非常适合实时检测与手机/嵌入式端侧部署 |
| **主要局限** | 1. **局部感受野受限**：单层卷积只能感知局部邻域，需要堆叠较深层数才能建立图像中远距离区域之间的全局关联<br>2. **对大尺度形变与旋转较敏感**：权重共享提供平移不变性，但对大幅度旋转、缩放仍依赖数据增强或多尺度设计 |

> **与 Vision Transformer（ViT）的关系**：在超大规模数据预训练和多模态统一架构（如视觉语言大模型）中，**Vision Transformer** 凭借自注意力机制的全局建模与扩展能力已成为重要主流；但在端侧推理、实时目标检测（如 YOLO）及中小数据场景下，CNN 依然不可替代。当前工业界也广泛采用 **CNN + Attention 混合架构**（前段用 CNN 高效提取局部空间细节，后段用注意力建模全局关系）以兼顾效率与精度。
